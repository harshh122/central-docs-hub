## System overview

## Components and extensions

The backend components comprise OSGi configurations, services, portlets, and resource commands across the project modules.

| Component | Type | Friendly URL / Config | OAuth Scopes / Details |
| :--- | :--- | :--- | :--- |
| `BatchDeploymentConfiguration` | Interface | `nl.batch.deployment.manager.configuration` | OCD configuration for staging and deployment directories. |
| `DatalakeConfiguration` | Interface | `nl.govcon.datalake.configuration` | OCD configuration handling access token URLs and client credentials. |
| `ExportConfiguration` | Interface | `nl.govcon.export.rest.service.internal.configurations` | OCD configuration managing export limits for Excel, CSV, and PDF formats. |
| `FragmentConfiguration` | Interface | `nl.govcon.grid.rest.service.util` | OCD configuration for site ID and fragment collection naming. |
| `BatchDeploymentPanelApp` | Class | `nl.batch.deployment.manager.application.list` | OSGi Component rendering the deployment panel application. |

| `GetImportTasksMVCResourceCommand` | Class | `nl.batch.deployment.manager.resource` | MVC Resource Command retrieving active and recent import tasks. |

## Data and integration points

The platform manages interactions across batch deployment pipelines, external datalake authentication, and object entry queries:

- **Batch Deployment Manager (`nl.batch.deployment.manager`)**: Coordinates file staging, deployment execution, package inspection, and MVC resource commands (`DeployPackageMVCResourceCommand`, `GetImportTasksMVCResourceCommand`, `GetPackagesMVCResourceCommand`). Configured via `BatchDeploymentConfiguration` with configurable recent import task limits.
- **Datalake Integration (`nl.govcon.datalake`)**: Manages external endpoint synchronization via `DatalakeConfiguration`, implementing OAuth client credentials workflows (`getClientId`, `getClientSecret`, `getAccessTokenUrl`, `getGrantType`).
- **Export & Grid Services (`nl.govcon-export-rest-service`, `nl.govcon-grid-rest-service`)**: Provides robust limits for tabular data exports (`ExportConfiguration`) and fragment collection targeting (`FragmentConfiguration`).
- **Account Utilities (`nl.govcon-account-utils`)**: Executes querying operations on local object entries using `LocalObjectEntryQuery` for text, numeric, and flag filtering expressions.
