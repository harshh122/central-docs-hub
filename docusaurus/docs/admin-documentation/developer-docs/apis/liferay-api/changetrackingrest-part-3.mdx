## Endpoints

### GET `/change-tracking-rest/v1.0/ct-remotes`

Retrieve a page of change tracking remote connections (`ResponseEntity<ChangeTrackingRest.v1.0.PageCTRemote>`).

| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `page` | query | string | No | Page number to retrieve |
| `pageSize` | query | string | No | Number of items per page |
| `search` | query | string | No | Search query string |
| `sort` | query | string | No | Sorting criteria |

**Response (200 OK)**

```json
{
  "items": [
    {
      "id": 1,
      "name": "Production Remote",
      "url": "https://remote.nlproducts.net/o"
    }
  ],
  "page": 1,
  "pageSize": 20,
  "totalCount": 1
}
```

---

### POST `/change-tracking-rest/v1.0/ct-remotes`

Create a new change tracking remote configuration (`ResponseEntity<ChangeTrackingRest.v1.0.CTRemote>`).

**Request Body**

```json
{
  "name": "Staging Remote",
  "url": "https://staging.nlproducts.net/o"
}
```

**Response (201 Created)**

```json
{
  "id": 2,
  "name": "Staging Remote",
  "url": "https://staging.nlproducts.net/o"
}
```

### POST `/change-tracking-rest/v1.0/ct-remotes/export-batch`

Trigger an asynchronous batch export of change tracking remotes (`ResponseEntity<Object>`).

| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `search` | query | string | No | Search filter criteria |
| `sort` | query | string | No | Sorting criteria |
| `callbackURL` | query | string | No | Optional webhook callback URL |
| `contentType` | query | string | No | Export content type (e.g., json, csv) |
| `fieldNames` | query | string | No | Specific fields to include in export |

**Response (200 OK)**

```json
{
  "status": "ACCEPTED"
}
```
