## Endpoints

### GET `/api/award/v1/federal-account-balances`

Get federal account balances

| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `type` | query | string | No | Type (e.g., AWARD_ID) |
| `value` | query | string | **Yes** | Award ID or identifier value |
| `page` | query | integer(int32) | No | - |
| `limit` | query | integer(int32) | No | - |

```json
{
  "content": [],
  "pageable": {
    "pageNumber": 0,
    "pageSize": 10
  },
  "totalElements": 0
}
```

---

### GET `/api/award/v1/by-generated-unique-award-id`

Get award detail by generated unique award id

Fetch full award details for a specific PIID (Procurement Instrument Identifier).

| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `generated-unique-award-id` | query | string | **Yes** | Generated unique award id |

:::warning[Error Codes]
- `400: Missing or invalid PIID`
- `500: Server error`
:::

```json
{
  "status": "success",
  "data": {
    "generatedUniqueAwardId": "CONT_AWD_...",
    "piid": "ABC123456",
    "awardAmount": 500000.00
  }
}
```

### GET `/api/award/v1/by-contract-number-and-award-id`

Get award detail by contract number and award id

Fetch full award details for a specific contract number and award id.

| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `contract-number` | query | string | **Yes** | Contract Number |
| `award-id` | query | string | **Yes** | Award Id |

:::warning[Error Codes]
- `400: Missing or invalid PIID`
- `500: Server error`
:::

```json
{
  "status": "success",
  "data": {
    "contractNumber": "GS-35F-0000A",
    "awardId": "12345",
    "description": "Contract details"
  }
}
```
