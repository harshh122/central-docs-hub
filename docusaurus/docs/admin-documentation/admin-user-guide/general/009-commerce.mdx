The Commerce page allows you to manage commercial operations, including customer contracts, invoices, and payments. Access this page by navigating to **Commerce** in the top navigation bar.

![Commerce](/img/admin/009-commerce-screenshot.png)

## Commerce navigation and client selection

Use the navigation menu and client selector to manage commercial workflows for specific organizations.

| Element | What it does |
| :--- | :--- |
| **Commerce** | Opens the Commerce drop-down menu containing **Customer Contract** and **Invoices and Payment**. |
| **Choose the client you want to work with** | Drop-down selection field to choose the active client for your current session. |
