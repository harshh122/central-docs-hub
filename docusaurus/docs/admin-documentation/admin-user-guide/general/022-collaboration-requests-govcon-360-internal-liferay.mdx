The Collaboration Requests page allows administrators to review, search, and manage incoming requests from users. You can access this page via the **Administration** module and review active items in the main data table.

![Collaboration Requests]( /img/admin/022-collaboration-requests-govcon-360-internal-liferay-screenshot.png)

## Page Layout and Search

The interface is structured around a main data table that displays pending and existing requests. 

| Element | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Search** | Text | No | Enter keywords to filter collaboration requests by user details. |
| **Add Collaboration Request** | Button | No | Click the blue **+** button to create a new collaboration request manually. |
| **Open Fields Menu** | Button | No | Click the dropdown caret in the table header to manage visible columns. |

## Collaboration Requests Table

The table lists all submitted collaboration requests with the following columns:

- **First Name**: The given name of the user who submitted the request.
- **Last Name**: The family name of the user.
- **Email Address**: The contact email address associated with the user.
- **Application Status**: Displays the current status of the request (e.g., **Pending**).
- **Create Date**: The timestamp indicating when the request was generated.
- **Actions**: Click the vertical three-dot icon in the final column to open contextual options for individual records, such as **Delete**.
