description: "Manage and review incoming affiliate program requests."

Review and manage incoming partner program applications under **Administration → Affiliate Requests**.

![Affiliate Requests](/img/admin/018-affiliate-requests-govcon-360-internal-liferay-screenshot.png)

## Affiliate requests table

The main workspace displays a searchable table of all submitted affiliate applications. You can sort columns or use the **Search** field to filter records by keywords.

| Column | Description |
| :--- | :--- |
| **First Name** | Applicant's first name. |
| **Last Name** | Applicant's last name. |
| **Email Address** | Contact email for the affiliate. |
| **Company Name** | Name of the applicant's organization. |
| **Application Status** | Current state of the request (e.g., Pending). |
| **Create Date** | Timestamp of when the request was submitted. |
