Manage invoices, track payment status, and organize billing information for your customers under the **Commerce** module by navigating to **Commerce → Marketing Management**.

![Marketing Management](/img/admin/014-marketing-management-screenshot.png)

## Overview and Metrics

The top section displays high-level metrics for your account to help you monitor billing health at a glance:

- **Outstanding**: Shows the total current unpaid balance.
- **Overdue**: Displays the count of overdue invoices.
- **Draft**: Shows the count of invoices currently saved in draft status.

## Invoices and Payment Controls

Use the filter controls and search bar to narrow down the invoice list by specific parameters.

| Element | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Search by recipient name or invoice numnber** | Text | No | Type a recipient name or invoice number to filter results. |
| **All Status** | Select | No | Filter invoices by their current payment or processing status. |
| **All Payment Method** | Select | No | Filter invoices by the method of payment (e.g., ACH). |
| **Upload Invoice** | Button | No | Select to upload a new invoice file into the system. |

## Invoice Table

The main table details your billing records with the following columns:

- **Name**: The recipient or organization being billed.
- **Invoice Number**: The unique identifier for the invoice.
- **Invoice Date**: The date the invoice was issued.
- **Due date**: The date payment is due.
- **Billing period**: The service timeframe covered by the invoice.
- **Amount**: The total financial amount due.
- **Payment Method**: The designated payment method used.
- **Status**: The current state of the invoice (e.g., Paid).
