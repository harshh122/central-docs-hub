Manage prospective client demo submissions using the Demo Requests form. Access this page by navigating to **Administration** within GovCon360.

![Demo Requests](/img/admin/021-demo-requests-govcon-360-internal-liferay-screenshot.png)

## General Information

Use the general information section to capture contact details, company information, and scheduling preferences for prospective leads.

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| **First Name** | Text | No | Prospect's first name. |
| **Last Name** | Text | No | Prospect's last name. |
| **Company Name** | Text | No | Name of the prospect's organization. |
| **Email Address** | Text | No | Direct email address for communication. |
| **Phone Number** | Text | No | Contact telephone number. |
| **Job Title** | Text | No | Professional title of the prospect. |
| **Demo Date** | Date/Time | No | Scheduled date and time for the demonstration. |
| **Message** | Textarea | No | Additional notes, questions, or specific areas of interest. |
