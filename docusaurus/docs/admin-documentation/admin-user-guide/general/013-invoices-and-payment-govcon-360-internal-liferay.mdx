Manage invoices, track payment status, and keep all billing information organized in one place for B2B customers from **Commerce → Invoices and Payment**.

## Summary cards

The top of the page displays summary metrics for your invoices:

- **Outstanding**: Shows the total monetary value of unpaid or outstanding invoices (defaulting to \$0).
- **Draft**: Displays the count of invoices currently saved as drafts.

## Search and filters

You can narrow down the invoice list using the available search bar and filter controls:

| Element | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Search by recipient name or invoice numnber** | Text | No | Enter keywords to instantly search records. |
| **All Status** | Dropdown | No | Filter invoices by their current status. |
| **All Payment Method** | Dropdown | No | Filter invoices by payment method (e.g., ACH). |

## Uploading and managing invoices

1. Click **Upload Invoice** in the upper-right corner of the main panel.
2. In the **Select Recipient** dialog box, select the **Recipient name** to automatically pull in associated payment terms and details.
3. Click **Continue** to proceed or **Cancel** to abort the upload.
