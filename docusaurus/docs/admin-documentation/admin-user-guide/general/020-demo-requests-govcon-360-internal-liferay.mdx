The **Demo Requests** page allows administrators to review, search, and manage incoming demonstration requests. You can reach this page through the top-level navigation and module menus.

## Managing demo requests

Use the main data table to view pending and scheduled demonstrations. The table displays key details for each request across several columns.

| Column | Description |
| :--- | :--- |
| **First Name** | The requester's first name. |
| **Last Name** | The requester's last name. |
| **Email Address** | The contact email for the requester. |
| **Demo Date** | The scheduled date and time for the demonstration. |
| **Company Name** | The organization associated with the request. |
| **Application Status** | The current status of the request (e.g., **Pending**). |

## Search and filters

To quickly locate specific submissions, use the **Search** field above the table to filter results by name, email, or company. You can also click column headers like **First Name**, **Last Name**, **Email Address**, **Demo Date**, **Company Name**, or **Application Status** to sort the table entries.

## Adding and modifying requests

1. Click the **Add Demo Request** button to create a new entry.
2. Use the **Open Fields Menu** or row-level **Actions** to modify existing records or remove outdated entries using the **Delete** option.
3. Navigate through larger result sets using the pagination controls at the bottom of the table, where you can adjust the view to show **20 Items** per page.
