Use the Reset Password page to update your account credentials. Access this page from your user profile settings to modify your security details.

![Reset Password](/img/admin/030-reset-password-govcon-360-internal-liferay-screenshot.png)

## Change Password

Complete the password form to update your credentials. Your new password must be different from any previously used passwords and must satisfy all security validation criteria listed on the page.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Current Password** | Password | Yes | Enter your existing account password. |
| **New Password** | Password | Yes | Enter your desired new password. |
| **Reenter Password** | Password | Yes | Re-enter your new password to confirm. |

### Password requirements

Your new password must meet the following criteria:
- Must be at least 8 characters
- Must contain an upper case letter
- Must contain a lower case letter
- Must contain a number
- Must contain a special character

### Actions

1. Enter your **Current Password**.
2. Type your new password into **New Password** and confirm it in **Reenter Password**.
3. Click **Change Password** to save your changes, or click **Cancel** to discard them.
