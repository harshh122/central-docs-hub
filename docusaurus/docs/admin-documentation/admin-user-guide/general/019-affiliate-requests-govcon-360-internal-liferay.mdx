Manage affiliate partnership requests and update application statuses from the Administration section. Navigate to **Administration** to access the affiliate request details form.

![Affiliate Requests](/img/admin/019-affiliate-requests-govcon-360-internal-liferay-screenshot.png)

## General information

The **General** section captures the primary contact and organization details for the affiliate request.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **First Name** | Text | No | The applicant's given name. |
| **Last Name** | Text | No | The applicant's surname. |
| **Company Name** | Text | No | The organization or company requesting affiliation. |
| **Email Address** | Text | No | The primary contact email address for the applicant. |

## Actions

The **Actions** section allows you to manage the review process for the submission.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Application Status** | Select | Yes | Tracks the current processing state of the request (default is **Pending**). |

## Metadata

Expand the **METADATA** section to view system tracking details, such as record creation dates, internal identifiers, and last modification timestamps. Use **Save** or **Cancel** to finalize or discard your updates.
