The Data Management module allows you to configure and monitor data ingestion schedules, parsers, and grid settings for your clients. Access this area via **Customer Content → Data Management** or by using the primary navigation bar.

## Client selection

1. Click the **Choose the client you want to work with** field.
2. Select the specific client organization from the dropdown menu to load their corresponding market intelligence and prospecting options.

## Data management options

The navigation dropdown under **Data Management** provides access to the following operational areas:

| Option | Description |
| :--- | :--- |
| **Ingestion Schedule** | Manage and configure automated data synchronization and import timelines. |
| **Schedule Summary** | Review an overview of active schedules and recent execution statuses. |
| **Ingestion Dashboard** | Monitor real-time metrics and logs related to incoming data feeds. |
| **Parser Emails** | Configure and manage email parsing rules for automated data extraction. |
| **Grid Management** | Customize data grid views, column configurations, and layouts. |
