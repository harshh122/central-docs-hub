Review system alerts, updates, and messages from your central feed. Access this page by clicking the notification icon in the top header or navigating through **Administration**.

## Notification views

Use the tabs below the **Notifications** heading to filter your messages:

| Tab | Description |
| :--- | :--- |
| **All** | Displays every notification you have received, both read and unread. |
| **Unread** | Displays only new, unread notifications. |

When no items are present, the page displays a message indicating that you are all caught up.
