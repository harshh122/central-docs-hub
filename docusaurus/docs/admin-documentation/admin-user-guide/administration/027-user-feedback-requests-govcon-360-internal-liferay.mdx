Review and manage user feedback and support queries submitted within the system. You can access this page via **Administration** → **User Feedback Requests**.

![User Feedback Requests](/img/admin/027-user-feedback-requests-govcon-360-internal-liferay-screenshot.png)

## Feedback details

Use the user feedback form to record contact details, inquiries, and application statuses.

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| **First Name** | Text | No | Submitter's first name. |
| **Last Name** | Text | No | Submitter's last name. |
| **Email Address** | Text | No | Contact email address. |
| **Company Name** | Text | No | Organization associated with the user. |
| **Message** | Textarea | No | Details of the feedback or inquiry. |
| **Application Status** | Select | Yes | Current processing status (e.g., **Pending**). |
| **Phone Number** | Text | No | Contact telephone number. |

## Managing feedback entries

1. Navigate to **Administration** → **User Feedback Requests**.
2. Complete or update the relevant user details in the form fields under **DETAILS**.
3. Set the **Application Status** using the dropdown menu.
4. Click **Save** to record changes or **Cancel** to discard them.
