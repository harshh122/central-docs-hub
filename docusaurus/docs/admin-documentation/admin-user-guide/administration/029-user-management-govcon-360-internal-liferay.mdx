The **User Management** page allows administrators to view and configure user accounts, roles, and seat and billing details. Navigate to this page by selecting **Administration** in the top navigation and opening the user profile view.

![User Management](/img/admin/029-user-management-govcon-360-internal-liferay-screenshot.png)

## Managing user accounts

The top section displays the user's name, assigned roles, and status indicators. You can modify user names or adjust administrative privileges using the available action buttons.

| Control | Description |
| :--- | :--- |
| **Go Back** | Returns to the previous user list view. |
| **Edit name** | Opens a modal to modify the user's display name. |
| **Deactivate user** | Revokes system access for the selected user account. |

:::warning
At least one admin must exist at all times. Administrative access cannot be removed and users cannot be deactivated until another admin is added to the system using **Add admin**.
:::

## Account details and seat billing

The lower section is divided into user identification properties and billing attributes.

- **Account details**: Displays the user's **First name**, **Last name**, **Email**, and assigned **Role** (**General user**, **Admin**). Note that email addresses are set at invite and are not editable.
- **Seat and billing**: Outlines subscription usage, including **Plan**, **Committed seats**, **Seats used**, and **Contract term**.
