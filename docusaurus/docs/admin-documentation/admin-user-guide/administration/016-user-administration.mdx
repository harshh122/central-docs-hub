The **User Administration** page allows you to oversee system users, configure access settings, and manage billing records. You can reach this page by navigating to **Administration** → **User Administration**.

## Invoices and payment overview

The main panel tracks key financial metrics and provides a searchable invoice table. 

| Element | Type / Action | Description |
| :--- | :--- | :--- |
| **Search by recipient name or invoice numnber** | Text | Filter invoices dynamically by recipient or number. |
| **All Status** | Dropdown | Filter the invoice list by payment status. |
| **All Payment Method** | Dropdown | Filter transactions by payment method. |
| **Upload Invoice** | Button | Upload a new billing record into the system. |

## Managing user access

Use the top navigation menu to switch between modules like **Accounts**, **Customer Content**, **Data Management**, **Commerce**, **Marketing Management**, and **Administration**. Hovering over **Administration** opens a dropdown menu containing **Analytics**, **Virtual Assistant Manager**, **User Administration**, and **Emails** to manage platform preferences and team permissions.
