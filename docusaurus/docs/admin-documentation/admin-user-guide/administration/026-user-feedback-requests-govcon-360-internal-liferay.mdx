View and manage user feedback submissions submitted by platform users under the **Administration** module. Access this view by selecting **Administration** from the main navigation menu.

![User Feedback Requests](/img/admin/026-user-feedback-requests-govcon-360-internal-liferay-screenshot.png)

## User feedback grid

The user feedback table displays all submitted feedback records with sorting and search capabilities. 

| Column | Description |
| :--- | :--- |
| **ID** | Unique identifier number for the feedback entry. |
| **First Name** | First name of the user who submitted the feedback. |
| **Last Name** | Last name of the user who submitted the feedback. |
| **Email Address** | Contact email address of the user. |
| **Company Name** | Associated company name of the submitter. |
| **Phone Number** | Contact phone number of the submitter. |
| **Message** | Content of the feedback request. |

## Managing feedback entries

1. Type keywords into the **Search** field to filter feedback records.
2. Click the **Search** button to execute your query.
3. Use the pagination controls at the bottom of the table to adjust items per page (default is **20 Items**) or navigate between pages.
4. Click the blue **+** button to manually add a new feedback request entry if needed.
