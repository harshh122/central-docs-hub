Manage customer contracts and seats allocation in GovCon360 by navigating to **Commerce → Customer Contract**.

![Customer Contract](/img/admin/010-customer-contract-govcon-360-internal-liferay-screenshot.png)

## Manage customer contracts

The **Customer Contract** page displays a table of existing recipient contracts and seat allocations. 

1. Use the **Search by recipient name** field to filter the contract list.
2. Click the **Add Customer Contract** button to create a new contract entry.
3. Review contract details across the columns including **Recipient Name**, **Start Date**, **End Date**, **Committed...**, **Billing Frequ...**, **Extra Price /...**, **Prorated Pri...**, **Free Trial**, and **Status**.
4. Use the row action icons to view or edit existing contracts.
