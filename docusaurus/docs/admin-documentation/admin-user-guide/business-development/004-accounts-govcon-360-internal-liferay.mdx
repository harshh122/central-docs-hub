The Accounts page allows you to view and configure business information, capabilities, and key representatives for your accounts. You can reach this page through the **Accounts** module navigation.

![Accounts](/img/admin/004-accounts-govcon-360-internal-liferay-screenshot.png)

## Business Overview

The **Business Overview** section guides you through the third step of account setup. Use the progress tracker at the top right to switch between **General Information**, **Point of Contact**, **Business Overview**, and **Company Details**.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Industry** | Dropdown / Text | Yes | Select or start typing an industry for the account. |
| **Capabilities** | Text / Tag input | Yes | Add capabilities associated with the account. |
| **Account Representative** | Text / Tag input | No | Assign an account representative. |
| **Customer Success** | Text / Tag input | No | Assign a customer success representative. |

## Navigation Actions

Use the buttons at the bottom of the form to move through the setup wizard:
- Click **Previous** to return to the previous step.
- Click **Next** to proceed to the next section of the account profile.
