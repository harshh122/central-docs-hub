The Accounts module allows you to set up and maintain organization profiles, including general information, subdomains, and branding. You can reach this page by navigating to **Accounts** from the main navigation menu.

![Accounts](/img/admin/002-accounts-govcon-360-internal-liferay-screenshot.png)

## General Information

The **General Information** step captures core organizational details required to set up your account profile. Use the multi-step progress bar at the top right to move between **General Information**, **Point of Contact**, **Business Overview**, and **Company Details**.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **UEI** | Text | Yes | Enter your organization's Unique Entity Identifier. |
| **Account Type** | Toggle | Yes | Switch between **B2C** and **B2B**. |
| **Enterprise** | Toggle | Yes | Select **NO** or **YES** for enterprise status. |
| **Organization Name** | Text | Yes | Enter the legal or operating name of your organization. |
| **Sub Domain** | Text | Yes | Enter your desired subdomain appended with the base domain (e.g., `.nlproducts.net`). |
| **Logo** | Upload | No | Upload a company logo to increase profile visibility with potential teaming partners using **Upload Logo**. |
