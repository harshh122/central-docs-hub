Submit and manage contact inquiries from users by accessing the **Contact Request** page.

![Contact Request](/img/admin/025-contact-request-govcon-360-internal-liferay-screenshot.png)

## General Information

The **General** section of the contact request form captures user details and inquiry information. Fill out the available fields to submit your request.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **First Name** | Text | No | Enter the submitter's first name. |
| **Last Name** | Text | No | Enter the submitter's last name. |
| **Company Name** | Text | No | Enter the name of the company or organization. |
| **Email Address** | Text | No | Enter a valid contact email address. |
| **Phone Number** | Text | No | Enter a contact telephone number. |
| **Message** | Textarea | No | Enter details or questions. Limited to 1000 characters. |
