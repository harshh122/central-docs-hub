Manage, view, and organize your client accounts directly from the **Accounts** module. You can navigate here by selecting **Accounts** from the main application navigation.

![Accounts Home](/img/admin/004-accounts-home-screenshot.png)

## Header elements

The top navigation bar provides access to platform search tools, notifications, and administrative settings. 

| Element | Description |
| :--- | :--- |
| **Accounts** | Primary navigation tab for client and account management. |
| **Customer Content** | Access repository content and customer-related files. |
| **Data Management** | Manage system records and data feeds. |
| **Commerce** | View transactions, billing, and order histories. |
| **Marketing Management** | Track campaigns, leads, and outreach efforts. |
| **Administration** | Configure user permissions and global system settings. |
| Notifications icon | View real-time system alerts and updates. |
| User profile menu | Access user account preferences and sign-out controls. |

## Account types and actions

The main content area lets you switch between account classifications and create new client records.

1. Click **B2B** to view business-to-business client accounts and enterprise profiles.
2. Click **B2C** to view business-to-consumer individual accounts.
3. Click **Add New Client** to open the creation form and onboard a new account into the system.

:::note
Sorting columns such as **Actions**, **Account Executive**, **Customer Success**, **Customer POC**, **UEI**, and **Cage Code** allows you to quickly organize large volumes of client data.
:::
