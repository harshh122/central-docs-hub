The Accounts page allows you to manage customer records, view client details, and organize your business portfolios. You can reach this page by navigating to **Accounts** in the main navigation menu.

![Accounts](/img/admin/001-accounts-govcon-360-internal-liferay-screenshot.png)

## Account management

Use the primary workspace to view, filter, and add client accounts.

| Element / Button | What it does |
| :--- | :--- |
| **B2B** | Filters the table to display business-to-business client accounts. |
| **B2C** | Filters the table to display business-to-consumer client accounts. |
| **Add New Client** | Opens the creation workflow to set up a new client account. |
| **Actions** | Provides options to edit, delete, or manage specific customer entries. |

## Account table details

The main table lists your existing client database with the following columns:

- **Customer Name**: Displays the name of the organization or individual client. Selecting a customer name opens their profile.
- **Account Executive**: Shows the assigned internal executive responsible for the account.
- **Customer Success**: Displays the team member managing client success.
- **Customer POC**: Lists the primary point of contact at the client organization.
- **UEI**: Shows the Unique Entity Identifier for government contracting compliance.
- **Cage Code**: Displays the assigned CAGE code for the entity.
