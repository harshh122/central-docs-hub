description: "Manage and view contact requests submitted to the system."

Manage and view contact requests submitted to the system from the **Administration** module.

![Contact Request](/img/admin/024-contact-request-govcon-360-internal-liferay-screenshot.png)

## Header elements

The header area displays the application title and standard navigation links. You can navigate across different modules such as **Accounts**, **Customer Content**, **Data Management**, **Commerce**, **Marketing Management**, and **Administration**.

## Contact Request table

The main panel lists all submitted contact requests in a tabular format. You can sort records by clicking column headers.

| Column | Description |
| :--- | :--- |
| **First Name** | The first name of the contact. |
| **Last Name** | The last name of the contact. |
| **Email Address** | The email address associated with the contact. |
| **Company Name** | The company name associated with the contact. |
| **Application Status** | The current status of the request (e.g., **Pending**). |
| **Create Date** | The date and time when the contact request was created. |

## Searching and filtering

1. Enter your search criteria in the **Search** field.
2. Click the **Search** button or press **Enter** to filter the list of contact requests.
3. Click the **Clear** button to reset your search.

## Pagination

Use the pagination controls at the bottom of the table to navigate through large lists. You can adjust the number of items displayed per page using the **20 Items** dropdown and use the arrow buttons to move between pages.
