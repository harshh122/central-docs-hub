The North American Industry Classification System (NAICS) page allows you to search, filter, and export industry classification codes and descriptions. Access this page via the reference navigation.

![Naics](/img/admin/033-naics-govcon-360-internal-liferay-screenshot.png)

## Search and filter NAICS codes

Use the search bar and filter criteria to locate specific industry codes and titles.

1. Select a search operator from the dropdown menu (such as **Contains**, **Starts with**, **Ends with**, or **Exact match**).
2. Enter your search terms in the **Type NAICs Code, Title, Description** field.
3. Click **Apply** to run the query.
4. Click **Export** to download the current view or dataset.

## Table navigation

The NAICS table displays entries with sorting and pagination controls.

| Control | Description |
| :--- | :--- |
| **NAICS Code** | Click to sort or invert sorting by code number. |
| **NAICS Description** | Click to sort by industry title or description. |
| **Entries Per Page** | Select how many records appear per page (default is 20). |
| **Jump To** | Type a specific page number and click **Go** to jump directly to that page. |
| Pagination arrows | Use the left and right arrows to move through pages. |
