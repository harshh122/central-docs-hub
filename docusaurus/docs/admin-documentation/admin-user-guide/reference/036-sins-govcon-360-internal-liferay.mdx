The Special Item Number (SIN) page allows you to view and search unique codes used by the GSA to categorize authorized products and services under a GSA Schedule contract. Access this page through your primary navigation menu.

![Sins](/img/admin/036-sins-govcon-360-internal-liferay-screenshot.png)

## SIN table and search

The main data table displays all available SIN records across multiple columns. You can use the column filter fields directly above the table headers to narrow down your results.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Search Category** | Text | No | Filter records by the broad category name. |
| **Search Sub Category** | Text | No | Filter records by the sub-category. |
| **Search SIN** | Text | No | Filter records by the specific SIN code. |
| **Search SIN Title** | Text | No | Filter records by the title of the SIN. |
| **Search SIN Description** | Text | No | Filter records by keywords in the description. |

Click any column header (such as **Category**, **Sub Category**, **SIN**, **SIN Title**, or **SIN Description**) to sort the table data in ascending or descending order. Use the pagination controls at the bottom or top right of the table to navigate through large entries.
