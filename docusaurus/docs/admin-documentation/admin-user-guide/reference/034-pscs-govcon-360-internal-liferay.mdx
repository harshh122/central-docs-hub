View, search, and export Product and Service Codes (PSCs) to support federal procurement classifications by accessing the reference tools.

![Product and Service Code (PSC)](/img/admin/034-pscs-govcon-360-internal-liferay-screenshot.png)

## Product and Service Codes

The **Product and Service (PSC)** table lists available codes, categories, and descriptions. You can use the search fields above each column to filter the table or click **Export** to download the data.

| Column / Field | Type | Required | Description |
| --- | --- | --- | --- |
| **Search PSC Code** | Text | No | Filter entries by specific PSC code. |
| **Search Level1 category Name** | Text | No | Filter entries by high-level category name. |
| **Search Level2 Category Name** | Text | No | Filter entries by sub-category name. |
| **Search PSC Name** | Text | No | Filter entries by PSC description or name. |
| **Export** | Button | No | Download the current PSC data table. |

## Table navigation

Use the pagination controls at the top and bottom of the table to manage your view:

1. Adjust the **Entries Per Page** dropdown to show more or fewer rows at once.
2. Type a page number into the **Jump To** field and click **Go** to navigate directly to a specific page.
3. Use the arrow controls (**First**, **Previous**, **Next**, **Last**) to page through the results.
