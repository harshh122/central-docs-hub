View, filter, and export Standard Industrial Classification (SIC) data to categorize industries and offices across your market research. Access this page via **Data Management** → **SIC** (or the top navigation shortcut).

![Sics](/img/admin/035-sics-govcon-360-internal-liferay-screenshot.png)

## Search and filter SIC codes

Use the search bar and operators at the top of the table to find specific SIC entries.

1. Click the operator dropdown (defaulting to **Contains**) to select a search method such as **Contains**, **Starts with**, **Ends with**, or **Exact match**.
2. Type your search criteria into the **Type SIC Code, Title, Office** field.
3. Click **Apply** to filter the table results.

## Table navigation and export

The SIC data table displays records with columns for **Code**, **Office**, and **Industry Title**. 

| Element | What it does |
| :--- | :--- |
| **Export** | Downloads the current SIC dataset for offline use. |
| **Entries Per Page** | Adjusts the number of rows displayed per page (e.g., **20** entries). |
| **Jump To** | Type a page number and click **Go** to navigate directly to a specific page. |
| Column Headers | Click **Code**, **Office**, or **Industry Title** to sort the table data in ascending or descending order. |
