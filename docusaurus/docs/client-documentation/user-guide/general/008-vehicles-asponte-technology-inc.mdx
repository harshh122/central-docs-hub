The Vehicles page allows you to search, filter, and analyze government contract vehicles, obligations, and associated agencies. Access this page through **Market Intel → Vehicles**.

## Search and filter

Use the search bar and filter controls to narrow down contract vehicles by keyword, title, funding agency, or awarding agency.

1. Type your search terms into the **Type Keyword** or **Type Contract Title, Funding agency, Awarding agency** search bar.
2. Select an operator from the dropdown (such as **Contains**).
3. Click **Apply** to execute your search.
4. Click **Filter** to configure advanced clauses and criteria using **Add Clause** and **Save Filter**.

## Contract vehicles table

The main panel displays a comprehensive data table containing details about each contract vehicle. 

| Column | Description |
| :--- | :--- |
| **Contract Key** | Shortened name or abbreviation of the vehicle. |
| **Total Obligation** | Total Dollar Obligation. |
| **Awarding Agency** | Government agency responsible for awarding the contract vehicle. |
| **Funding Agency** | Government agency providing funding for the contract vehicle. |
| **Ceiling Amount** | Maximum funding limit available for awards under this vehicle. |
| **Total Contracts** | Total Contract count. |
| **Total Awards** | Total Award Count. |

Click on any column header to sort the table data in ascending or descending order.

## Exporting data

To export records from the table, click the **Export** button located above the top-right corner of the data grid to open the export options and download your filtered data.
