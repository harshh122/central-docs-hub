Manage user profiles, account details, and seat allocations through **Administration → User Management**. 

## User profile and account details

The top profile section displays the user's name, email address, current status badge (such as **Active**), and assigned permission tags (such as **GOVCON360 User** or **GOVCON360 Client Admin**). 

| Control / Field | Description |
| :--- | :--- |
| **Go Back** | Returns you to the previous user list view. |
| **Edit name** | Allows you to update the user's display name. |
| **Deactivate user** | Revokes platform access for the selected user. |
| **Grant admin access** | Elevates the user's privileges to include administrative controls. |

The **Account details** section outlines specific user metadata, including **First name**, **Last name**, **Email**, **Role**, **Sign-in method**, **Two-factor authentication**, **Added** date, and **Last sign-in** timestamp.

## Seat and billing

The **Seat and billing** card displays subscription allocations for the user, detailing whether the account occupies a committed seat alongside plan terms and billing statuses. The **Admin access** panel summarizes administrator privileges and management options.
