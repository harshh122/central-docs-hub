The Notifications page displays your system alerts, messages, and updates. You can reach this page by clicking the notification bell icon in the top header.

![Notifications](/img/client/002-notifications-asponte-technology-inc-screenshot.png)

## Notification filters

The main content area includes filtering tabs to help you organize your alerts.

| Element | Description |
| :--- | :--- |
| **All** | Displays all system notifications regardless of their read status. |
| **Unread** | Displays only unread notifications, showing the active count in parentheses. |

When you have no active items, the system indicates that you are all caught up. After reviewing your notifications, you can return to your [Dashboard](./dashboard.mdx) to continue working.
