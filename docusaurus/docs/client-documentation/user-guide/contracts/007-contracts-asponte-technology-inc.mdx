The Contracts page allows you to search, filter, and analyze government contracts. Access this page by clicking **Contracts** in the top navigation menu.

## Search and filter contracts

Use the search bar and filter controls at the top of the page to locate specific contract records.

1. Click the **Keyword** or search input box and type your search terms (such as a vehicle, contract number, recipient, or agency name).
2. Select an operator from the dropdown menu (such as **Contains**, **Starting**, **Ending**, or **Exact match**).
3. Click **Apply** to execute your search.
4. Click **Filter** to build advanced queries with clauses or apply saved filters.

## Contract records table

The main data table displays all matching contracts and includes columns for vehicle, contract number, title, total obligation, and recipient.

| Column | Description |
| :--- | :--- |
| **Vehicle** | Vehicle associated with the award. |
| **Contract #** | Unique identifier assigned to the contract. |
| **Contract Title** | Description or title of the contract. |
| **Total Obligation** | Total obligated funding committed under the contract. |
| **Recipient** | Entity or organization awarded the contract. |
| **Parent Recipient** | Parent organization associated with the contract. |

Click on any column header to sort the table data. Use the pagination controls at the bottom of the table to navigate through pages or export records using the **Export** button.
