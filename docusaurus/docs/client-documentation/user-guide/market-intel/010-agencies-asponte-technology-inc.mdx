The Agencies page allows you to search, filter, and review government agencies, their hierarchy levels, and associated metadata. Navigate to this page via **Market Intel** → **Agencies**.

![Agencies](/img/client/010-agencies-asponte-technology-inc-screenshot.png)

## Search and filter agencies

Use the search bar and filter controls to narrow down the agency directory.

1. Click **Keyword** or **Filter** to open the search and filtering options.
2. Enter your search terms in the **Type Agency, Top Level Agency** field.
3. Select an operator such as **Contains** from the dropdown list.
4. Click **Apply** to execute the search filter.

| Element | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| **Keyword** / **Filter** | Button | No | Opens search and advanced filtering options. |
| **Type Agency, Top Level Agency** | Search | No | Main search input for querying specific agencies. |
| **Apply** | Button | No | Applies the selected search criteria or filters. |

## Agency directory table

The main panel displays a comprehensive list of government entities containing the following columns:

| Column Header | Description |
| :--- | :--- |
| **Agency** | Official name of the government agency or office. |
| **Acronym** | Shortened name or abbreviation of the agency. |
| **Agency Level** | Hierarchy level of the agency within the government structure. |
| **Parent Agency** | Parent government department or higher-level agency associated with this entity. |
| **CGAC** | Treasury Common Government Accounting Classification code. |
| **Description** | Summary information regarding the agency's mission or function. |
| **Location** | Physical address or headquarters location. |

## Exporting records

To download agency data:

1. Click **Export** in the top-right corner of the table view.
2. Select your export parameters and options.
3. Click **Export records** to complete the download.
