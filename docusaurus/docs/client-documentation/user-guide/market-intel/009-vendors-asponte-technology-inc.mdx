Explore and manage vendor profiles, market intelligence, and contract recipients by navigating to **Market Intel → Vendors**.

![Vendors](/img/client/009-vendors-asponte-technology-inc-screenshot.png)

## Search and Filter Vendors

Use the search bar and filter tools to narrow down the vendor list by recipient name, business type codes, parent legal business name, or city.

1. Type your search criteria into the **Type Recipient Name, Business Type Codes, Parent Legal Business Name, City** search input.
2. Select an operator from the dropdown (such as **Contains**).
3. Click **Apply** to execute the search.
4. Click **Filter** to access advanced filtering options and saved filter lists.

## Vendor Data Table

The main data grid displays a comprehensive list of vendors and contract recipients. 

| Column | Description |
| :--- | :--- |
| **Recipient** | Organization or entity receiving the award or contract. |
| **Parent Recipient** | Legal name of the recipient’s parent organization or company. |
| **Business Type** | Classification codes and socioeconomic indicators for the vendor. |
| **Top 5 Prime Customer** | Primary government customers associated with the vendor. |

## Export Options

Click the **Export** button in the top right corner to export vendor records and data lists for offline analysis and reporting.
