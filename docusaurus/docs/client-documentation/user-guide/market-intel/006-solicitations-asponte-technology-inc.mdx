The Solicitations page allows you to search, filter, and view government procurement opportunities and contract notices. You can access this page by navigating to **Market Intel** → **Solicitations**.

## Search and Filter

Use the search bar and filter tools to narrow down the solicitation records.

1. Click **Keyword** or use the dropdown to select match criteria such as **Contains**.
2. Enter your search criteria in the **Type Solicitation Title, Solicitation Number** field.
3. Click **Apply** to execute the search.
4. Use the **Filter** button to apply advanced clauses, save filters, or manage saved filter lists.

## Solicitations Data Table

The main data table displays all matching solicitation entries across multiple columns. 

| Column | Description |
| :--- | :--- |
| **Solicitation #** | Unique identifier assigned to the solicitation notice. |
| **Solicitation Title** | The title and description of the procurement opportunity. |
| **Top Office/ Agency Name** | The issuing government office or agency. |
| **Posted Date** | Date when the solicitation was published. |
| **Set Aside** | Small business or socio-economic set-aside category. |
| **Type** | The procurement notice type (e.g., Solicitation, Combined Synopsis, Sources Sought). |

## Exporting Records

Click the **Export** button in the top right corner of the table area to export solicitation records for external reporting and offline analysis.
