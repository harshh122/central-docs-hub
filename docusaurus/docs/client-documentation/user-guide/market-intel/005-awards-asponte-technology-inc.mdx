Explore federal contract awards, funding obligations, and recipient information through the Market Intel module. Access this page by navigating to **Market Intel** → **Awards**.

![Awards](/img/client/005-awards-asponte-technology-inc-screenshot.png)

## Search and filter awards

Use the search bar and filter controls at the top of the awards table to narrow down records by specific criteria.

1. Select a search operator from the dropdown (such as **Contains**).
2. Enter your search terms in the **Type Vehicle, Contract, Award Id, Awarding Office, Funding Office, Recipient** field.
3. Click **Apply** to execute your search.
4. Click **Filter** to configure advanced query parameters, add clauses, or manage saved filters.

## Awards table data

The main data grid organizes award records across multiple columns. Click any column header to sort the table dynamically.

| Column | Description |
| :--- | :--- |
| **Vehicle** | Vehicle associated with the award. |
| **Contract #** | Name or identifier of the awarded contract. |
| **Award ID** | Unique identifier assigned to the award record. |
| **Total Obligation** | Total obligated funding amount committed under the award. |
| **Parent Recipient** | The parent organization of the award recipient. |
| **Recipient** | The specific entity receiving the award. |

## Exporting data

Click the **Export** button in the top-right corner of the table interface to download award records for offline analysis and reporting.
