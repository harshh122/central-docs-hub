## Header elements

The public header provides access to core platform sections and conversion actions.

| Element | What it does |
| :--- | :--- |
| **Home** | Navigates back to the main landing page. |
| **Solutions For** | Opens a dropdown menu of targeted solutions. |
| **Features** | Displays platform capabilities. |
| **Pricing** | Views available subscription tiers. |
| **Resources** | Accesses educational materials and guides. |
| **About** | Explores company information and background. |
| **Explore** | Discovers additional platform offerings. |
| **Schedule a Demo** | Requests a personalized walkthrough. |
| **Login** | Accesses your secure account. |

## The challenge of managing joint bids

Review common pain points when bidding on government contracts as a team, including **Finding Vetted Partners**, **Disorganized Collaboration**, and **Unclear Leadership**. 

Use the **Before** and **With GovCon360** buttons to compare traditional teaming hurdles against streamlined collaborative workflows.

## Cookie preferences

Manage your privacy choices using the cookie notification banner at the bottom of the screen.

1. Click **Customize** to adjust your tracking preferences.
2. Click **Reject all** to decline non-essential cookies.
3. Click **Accept all** to enable all cookies and personalized content delivery.
