Explore tailored solutions for building a winning pipeline and capturing more federal contracts on the Business Developers page, accessed via the public website navigation under **Solutions For**.

![Business Developers]( /img/public/003-business-developers-govcon-360-public-site-liferay-screenshot.png )

## Header and navigation

The top header provides global navigation across the public site, allowing you to access key marketing and product pages before signing in to your account.

| Element | Description |
| :--- | :--- |
| **Home** | Returns to the main landing page. |
| **Solutions For** | Opens a dropdown menu of audience-specific solutions, including Business Developers. |
| **Features** | Displays platform capabilities and core tools. |
| **Pricing** | Outlines subscription plans and tiers. |
| **Resources** | Provides guides, documentation, and educational materials. |
| **About** | Shares company background and mission information. |
| **Explore** | Navigates to additional exploratory content and tools. |
| **Schedule a Demo** | Opens a request form to book a personalized walkthrough of the platform. |
| **Login** | Directs existing users to the sign-in portal to access their dashboard. |

## The challenges of federal pipeline and account management

The main content area highlights common obstacles faced during federal capture and account management, including scattered pipelines, data silos, and identifying strategic partners. Use the **Schedule a Demo** button to learn how GovCon360 solves these hurdles.
