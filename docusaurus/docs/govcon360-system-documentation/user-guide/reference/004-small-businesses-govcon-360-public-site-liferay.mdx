The Small Businesses page introduces government contracting tools tailored to help small teams break into the federal market. You can reach this page from the public navigation menu by selecting **Solutions For** and clicking on small business solutions.

![Small Businesses](/img/public/004-small-businesses-govcon-360-public-site-liferay-screenshot.png)

## Header elements

The top navigation bar provides quick access to main site sections and account actions.

| Element | What it does |
| :--- | :--- |
| **Home** | Returns you to the main public landing page. |
| **Solutions For** | Displays a dropdown menu of target audiences and industries. |
| **Features** | Displays a dropdown menu of platform capabilities and tools. |
| **Pricing** | Opens the subscription and pricing tiers page. |
| **Resources** | Opens educational materials, guides, and documentation. |
| **About** | Provides information about the company and team. |
| **Explore** | Opens additional platform exploration options. |
| **Schedule a Demo** | Opens a form to request a personalized software demonstration. |
| **Login** | Navigates to the sign-in screen to access your account. |

## Cookie consent banner

When you first visit the site, a cookie consent banner appears at the bottom of the screen to manage your privacy preferences.

| Element | What it does |
| :--- | :--- |
| **Customize** | Opens preferences to select specific cookie categories. |
| **Reject all** | Declines all non-essential tracking cookies. |
| **Accept all** | Accepts all cookies to ensure the best possible browsing experience. |
