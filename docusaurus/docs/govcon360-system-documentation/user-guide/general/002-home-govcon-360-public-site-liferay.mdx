Welcome to the GovCon360 public site and home page, where you can explore government contracting tools, software features, pricing, and resources. Navigate to the site to learn about simplified government contracting software and access your account.

![Welcome](/img/public/002-home-govcon-360-public-site-liferay-screenshot.png)

## Header elements

The header provides top-level navigation across the public website and direct access to your user account.

| Element | What it does |
| :--- | :--- |
| **Home** | Returns you to the main landing page. |
| **Solutions For** | Displays industry and business solutions. |
| **Features** | Outlines core platform capabilities and tools. |
| **Pricing** | Views available plans and pricing options. |
| **Resources** | Accesses guides, articles, and documentation. |
| **About** | Explains company background and mission. |
| **Explore** | Discovers additional platform insights. |
| **Login** | Opens the authentication screen to sign in to your workspace. |

## Cookie and privacy preferences

When visiting the site, you can manage your cookie preferences using the prompt at the bottom of the screen.

| Button | What it does |
| :--- | :--- |
| **Customize** | Opens preferences to select specific cookie categories. |
| **Reject all** | Declines non-essential cookies. |
| **Accept all** | Accepts all cookies for personalized content and analytics. |
| **Cookie Settings** | Manages existing cookie permissions. |
| **Accessibility Settings** | Adjusts site display for accessibility needs. |
