Welcome to the GovCon360 public site, where you can explore government contracting software and tools designed to simplify the federal marketplace. Access the public site by navigating to the main landing page to learn about core features, solutions, pricing, and resources.

![Welcome](/img/public/001-home-govcon-360-public-site-liferay-screenshot.png)

## Header navigation

The top navigation bar provides quick access to platform information and authentication options.

| Element | Description |
| :--- | :--- |
| **Home** | Returns you to the main landing page. |
| **Solutions For** | Displays target audience solutions and use cases. |
| **Features** | Outlines core platform capabilities and tools. |
| **Pricing** | Views available subscription plans and tiers. |
| **Resources** | Access guides, documentation, and educational materials. |
| **About** | Learn more about the company and mission. |
| **Explore** | Discover additional tools and market intelligence offerings. |
| **Login** | Access your account to sign into the application. |

## Main landing page

The main hero section highlights core offerings with a direct call to action to **Schedule a Demo**. Below the hero banner, the **CORE FEATURES** section introduces tools built to help small businesses find and win government work.

## Cookie preferences

When visiting the site for the first time, a cookie consent banner appears at the bottom of the screen allowing you to manage your privacy settings.

| Button | What it does |
| :--- | :--- |
| **Customize** | Opens granular settings to configure individual cookie categories. |
| **Reject all** | Declines all non-essential cookies. |
| **Accept all** | Accepts all cookies to ensure the best possible site experience. |
| **Cookie Settings** | Re-opens the preference center for ongoing adjustments. |
| **Accessibility Settings** | Adjusts site accessibility features and viewing options. |
