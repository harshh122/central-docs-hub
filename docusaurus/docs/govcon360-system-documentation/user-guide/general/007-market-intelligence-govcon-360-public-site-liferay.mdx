The Market Intelligence overview page provides insight into federal market data, historical spend, agency structures, and vendor entities. You can navigate through solutions, features, pricing, and resources from the header elements, or click **Schedule a Demo** or **Login** to access your account.

## Header elements

The top navigation bar contains links to explore platform capabilities and access your portal.

| Element | What it does |
| :--- | :--- |
| **Home** | Returns you to the main landing page. |
| **Solutions For** | Displays target audience solutions. |
| **Features** | Explores platform features like market intelligence. |
| **Pricing** | Views subscription and package options. |
| **Resources** | Accesses guides, documentation, and help articles. |
| **About** | Learn more about the organization. |
| **Explore** | Discovers additional platform tools and data sets. |
| **Schedule a Demo** | Opens a request form to book a live product walkthrough. |
| **Login** | Navigates to the sign-in screen to access the application. |

## Cookie and privacy preferences

When visiting the site, a cookie consent banner appears at the bottom of the screen to manage your tracking preferences.

- **Customize**: Opens detailed preference settings to choose which cookies to allow.
- **Reject all**: Denies non-essential cookies.
- **Accept all**: Approves all cookies for full site functionality and personalized content.
